# Vivek — Personal Website

Personal page for **Vivekananda Reddy Murugesh** — Cybersecurity Engineer
securing web applications, APIs, cloud, and network environments.

Light, clean, minimal. System fonts, content-first, dark-mode toggle.
No frameworks, no build step, no trackers.

## Structure

```
index.html                  Single page
assets/css/style.css        Design system (light + dark)
assets/js/main.js           Theme toggle + subtle reveal
assets/img/favicon.svg      Favicon
assets/resume/              Résumé PDF (downloadable)
```

## Run locally

```bash
python -m http.server 8000
```

## Deploy

Push to `main` — GitHub Pages serves the repo root automatically.
