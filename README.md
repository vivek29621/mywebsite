# vivek.murugesh — Personal Website

Personal portfolio for **Vivekananda Reddy Murugesh** — Cybersecurity Engineer
with 3+ years securing web applications, APIs, cloud, and network environments.

![status](https://img.shields.io/badge/status-live-34d399)

## Stack

- Vanilla HTML / CSS / JS — zero dependencies, no build step
- Inter + JetBrains Mono (Google Fonts)
- Dark, security-inspired premium aesthetic
- Fully responsive, reduced-motion aware

## Structure

```
index.html                        Single-page portfolio
assets/css/style.css              Design system + layout
assets/js/main.js                 Nav, scroll reveal, active sections
assets/img/favicon.svg            Shield favicon
assets/resume/                    Résumé PDF (downloadable)
```

## Run locally

```bash
python -m http.server 8000
# or any static server — open http://localhost:8000
```

## Deploy

Push to `main` — GitHub Pages serves the repo root automatically
(Settings → Pages → Deploy from branch `main` / `/root`).
