# Vivek Murugesh — Personal Website

Personal page for **Vivekananda Reddy Murugesh** — Cybersecurity Engineer
with 3+ years securing web applications, APIs, cloud, and network environments.

Pure HTML. No CSS, no JavaScript, no frameworks, no build step, no trackers.
In the spirit of [Paul Graham's site](https://paulgraham.com) — the entire page
is ~5 KB of semantic markup and loads instantly on anything with a browser.

## Structure

```
index.html                        The whole site (5 KB)
assets/img/favicon.svg            Shield favicon
assets/resume/                    Résumé PDF (downloadable)
```

## Run locally

```bash
python -m http.server 8000
# or just double-click index.html — it needs nothing
```

## Deploy

Push to `main` — GitHub Pages serves the repo root automatically
(Settings → Pages → Deploy from branch `main` / `/root`).
